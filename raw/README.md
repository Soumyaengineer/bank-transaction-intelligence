# Raw data (not committed)

Raw files are excluded from version control due to size (~1.4 GB total).

**Source:** Kaggle — Financial Transactions Dataset: Analytics
https://www.kaggle.com/datasets/computingvictor/transactions-fraud-datasets

**Files expected in this folder:**

| File | Description |
|---|---|
| transactions_data.csv | Card transactions (fact source) |
| users_data.csv | Customer demographics |
| cards_data.csv | Card attributes per customer |
| mcc_codes.json | Merchant category code lookup |
| train_fraud_labels.json | Fraud labels keyed by transaction id |

Download date, licence, and verified row counts: see docs/data_provenance.md (added in step 2).

To reproduce: download from the Kaggle link above and place the five files in this folder.
